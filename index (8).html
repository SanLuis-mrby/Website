Computer Troubleshooting Guide

Troubleshooting is the process of finding the cause of a problem and fixing it. Almost every computer user runs into problems at some point: a slow computer, a frozen screen, no internet, or a program that will not open. Most of these problems can be solved at home by following a few logical steps.

This guide is divided into topics. Choose the one that matches your problem, or read the general steps below first.

The 7-Step Troubleshooting Method

  1. Identify the problem. What exactly is happening? Write down any error message and what you were doing when it started.
  2. Check the simple things. Is it plugged in? Is it turned on? Is the volume up? Is the cable firmly connected?
  3. Restart. Restarting clears the computer's temporary memory and fixes many small glitches.
  4. Think about what changed. Did you install a new program, update Windows, or plug in new hardware just before the problem began?
  5. Research. Search the exact error message online. Someone has probably solved it already.
  6. Try one fix at a time. Test after each change so you know what worked. Changing many things at once makes it hard to find the real cause.
  7. Document the solution. Write down what fixed it so you can solve it faster next time.
