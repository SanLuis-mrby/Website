Internet and Network Problems

An internet connection depends on several parts working together: your computer, the router, the modem, and your internet service provider (ISP). A problem in any one of them can cut your connection. The key to fixing network problems is finding out which part is failing.

Step 1: Find Where the Problem Is

  • Only one device is affected: The problem is probably on that device.
  • All devices are affected: The problem is probably the router, modem, or ISP.
  • Only one website is affected: The website itself may be down.

No Internet Connection

  1. Check that WiFi is turned on and Airplane mode is off.
  2. Check that the network cable is firmly plugged in if you use a wired connection.
  3. Restart your computer.
  4. Unplug the router and modem from power. Wait 30 seconds, plug the modem in first, wait a minute, then plug in the router.
  5. Forget the WiFi network in settings, then reconnect and type the password again.
  6. Run the Windows Network Troubleshooter by right-clicking the network icon and choosing Troubleshoot problems.
  7. If other devices also cannot connect, contact your internet provider.

Connected to WiFi but No Internet

This means your computer is talking to the router, but the router cannot reach the internet.

  • Check the lights on the modem. A red or blinking light usually means a problem with the line.
  • Restart the modem and router.
  • Open Command Prompt and type ipconfig /release, then ipconfig /renew.
  • Type ipconfig /flushdns to clear the DNS cache.
  • Call your provider to check for an outage in your area.

Slow Internet

  1. Run a speed test and compare the result with the plan you pay for.
  2. Move closer to the router or remove obstacles such as walls and metal objects.
  3. Disconnect devices that are not in use. Streaming and downloads on other devices use bandwidth.
  4. Close background programs that are downloading or updating.
  5. Try a wired connection with an Ethernet cable. It is usually faster and more stable than WiFi.
  6. Restart the router. If it runs for months, it may slow down.
  7. Change the WiFi channel in the router settings if many neighbors use the same channel.

Websites Will Not Load

  • Check whether other websites work. If they do, the one site may be down.
  • Clear the browser cache and cookies.
  • Try a different browser.
  • Disable browser extensions one by one to find a faulty one.
  • Change your DNS server to a public one such as 8.8.8.8 or 1.1.1.1.
  • Check the date and time on your computer. A wrong date can block secure websites.

Router Lights Guide

Light Normal State If It Is Off or Red
Power Solid green Check the power adapter and outlet
Internet / WAN Solid or blinking green Line problem; restart, then call the provider
WiFi Solid or blinking WiFi may be disabled in router settings
LAN Blinking when a cable is connected Check the Ethernet cable

Tip: Change the default router password and use WPA2 or WPA3 security so strangers cannot use your WiFi.
