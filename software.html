Software and Performance Problems

Software means the programs and operating system that run on the computer. Software problems include slow performance, freezing, crashing programs, and error screens. They are usually easier to fix than hardware problems and do not require opening the computer.

Computer Is Running Slow

Common causes

  • Too many programs running at the same time.
  • Too many programs starting automatically when the computer turns on.
  • The hard drive is almost full.
  • Not enough memory (RAM).
  • Malware running in the background.

Steps to fix

  1. Restart the computer.
  2. Press Ctrl + Shift + Esc to open Task Manager. Look at which programs use the most CPU, memory, or disk. Select one you do not need and click End task.
  3. Open the Startup tab in Task Manager and disable programs you do not need at startup.
  4. Uninstall programs you no longer use from Settings > Apps.
  5. Delete temporary files using Disk Cleanup or Storage settings.
  6. Run a full antivirus scan.
  7. Install all available system updates.

Computer Keeps Freezing

  1. Wait one or two minutes. The computer may be busy and will recover.
  2. Press Ctrl + Alt + Delete and open Task Manager to close the program that is not responding.
  3. If nothing responds, hold the power button for 5 to 10 seconds to force a shutdown.
  4. After restarting, check that the computer is not overheating (see the Hardware page).
  5. Make sure at least 15% of the hard drive is free.
  6. Update drivers, especially the graphics driver.

A Program Will Not Open or Keeps Crashing

  • Close the program completely using Task Manager and open it again.
  • Restart the computer.
  • Check whether an update is available for the program.
  • Right-click the program and choose Run as administrator.
  • Uninstall the program and install a fresh copy from the official website.
  • Check that the program is compatible with your version of Windows.

Blue Screen of Death (BSOD)

A blue screen appears when Windows meets an error it cannot recover from. It shows a sad face and a stop code such as CRITICAL_PROCESS_DIED or MEMORY_MANAGEMENT.

  1. Write down or take a photo of the stop code.
  2. Let the computer restart. A single blue screen may never happen again.
  3. Unplug any new devices you recently connected.
  4. Uninstall recently installed programs or drivers.
  5. Start in Safe Mode and use System Restore to return to an earlier working state.
  6. Open Command Prompt as administrator and run sfc /scannow to repair damaged system files.
  7. If blue screens continue, test the memory (RAM) with Windows Memory Diagnostic.

Not Enough Storage Space

  • Empty the Recycle Bin.
  • Delete files in the Downloads folder you no longer need.
  • Turn on Storage Sense in Settings to remove temporary files automatically.
  • Move photos, videos, and large files to an external drive or cloud storage.
  • Uninstall large programs and games you do not use.

Windows Update Problems

  1. Make sure you have a stable internet connection and enough storage space.
  2. Restart the computer and try the update again.
  3. Run the Windows Update troubleshooter from Settings > System > Troubleshoot.
  4. Disconnect extra USB devices during the update.
  5. If the update is stuck, wait at least an hour before forcing a restart.

Useful Keyboard Shortcuts

Shortcut What it does
Ctrl + Shift + Esc Opens Task Manager
Ctrl + Alt + Delete Opens the security screen
Windows + L Locks the computer
Windows + R Opens the Run box
Alt + F4 Closes the current window
